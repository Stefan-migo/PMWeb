- L21 — `useReducedMotion()` de framer sólo se resuelve después del montaje. Cambiar el elemento (div plano) o `initial` cuando el hook cambia dejaba el nodo con el `style="opacity:0"` que puso framer, porque React reutiliza el nodo y no borra estilos que no declaró. La solución estable es CSS: `@media (prefers-reduced-motion: reduce) { .shell [data-reveal] { opacity: 1 !important; transform: none !important } }`, y que la animación sea sólo una mejora progresiva.
